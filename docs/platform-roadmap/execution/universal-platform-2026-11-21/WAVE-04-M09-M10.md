# Wave 4 — Visual Application Builder and AI-Native Platform (M09–M10)

**Status:** milestone-specific universal visual builder and agent platform **NOT EVIDENCED/NOT CERTIFIED**. Existing Vibress Studio is a Lexical content editor and reusable capability; do not call it an application page/data/action builder. Existing CMS AI integrations do not certify a universal agent development SDK.

**Prerequisite:** stable M03 IR, M04 generated scoped runtime, M07 public SDK and relevant Wave3 security/GA acceptance. Optional isolated prototypes do not authorize general runtime expansion. End-of-M09 one full visual/security/RTL test cycle; end-of-M10 one full agent/MCP security/eval cycle. A06 independent review and owner-authorized merge for each milestone.
