# Vibress v1.0.0 — Official General Availability Release

We are proud to announce the official open-source **v1.0.0 General Availability (GA)** release of **Vibress**!

Vibress is an open-source, full-stack, high-performance Content Management System and publishing engine designed for modern creators, publishers, and development teams.

---

## Highlights

* **Modern Full-Stack Architecture:** Decoupled Fastify REST API, Next.js 14 Server-Side Rendered (SSR) public website, and reactive Vite + React Single Page Applications for Admin and Member Portal.
* **Studio Block Editor:** Real-time CRDT-synchronized collaborative editor with 13 canonical cards (`Callout`, `Button`, `Bookmark`, `Gallery`, `Video`, `Audio`, `File`, `Divider`, `Product`, `Embed`, `Header`, `Markdown`, `HTML`).
* **Arabic-First Multilingual & RTL:** Native RTL layout detection, Umm al-Qura Hijri calendar formatting, Arabic search normalization, and multi-language translation management.
* **Memberships & Subscriptions:** Tiered subscription products, gated content access, Stripe checkout and customer portal integration, and transactional email newsletters.
* **Sub-Millisecond Search:** Full-text and fuzzy search indexed with PostgreSQL `pg_trgm` GIN indexes delivering sub-millisecond query latencies.
* **Zero-Downtime Microservice Topology:** Production Docker Compose architecture with strict internal database isolation and non-root unprivileged container runtimes.

## Security Hardening

* **Centralized RBAC:** All administrative routes guarded by `@vibress/security` with strict role permissions (`Owner`, `Admin`, `Editor`, `Author`, `Contributor`).
* **Publication Boundary Isolation:** Fastify gateway strips unauthenticated or spoofable tenant headers (`x-publication-id`, `x-workspace-id`, `x-tenant-id`).
* **Secure Staff Auth Lifecycle:** Cryptographically hashed single-use password reset tokens, token invalidation upon use, and multi-device session revocation on password changes.
* **First-Run Lockout:** One-time initial setup wizard permanently locks down once an Owner account exists (`OWNER_ALREADY_EXISTS`).

## Self-Hosting & Deployment

Vibress provides complete containerized deployment with one command:

```bash
git clone https://github.com/AbdullahZaher/vibress.git
cd vibress
cp infrastructure/env.prod.example .env
# Edit .env with your secrets
./scripts/deploy-production.sh
```

2. Pull the latest release: `git pull origin main --tags && git checkout v1.0.0`
3. Run the automated deployment script: `./scripts/deploy-production.sh`

## Known External Configuration Requirements

For internet-facing production instances, operators must configure their external infrastructure:
- **DNS:** Point your domain A/AAAA records to your server IP.
- **TLS:** Terminate HTTPS via NGINX, Caddy, or Cloudflare edge.
- **SMTP:** Configure outbound email credentials for invitations and newsletters.
- **Stripe:** Set live keys and configure webhook endpoint in Stripe dashboard.
- **S3 / MinIO:** Configure bucket credentials when using S3 storage provider.
