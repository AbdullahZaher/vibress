## 2. Deployment Architecture
Vibress operates as a modular full-stack application with independently containerized components orchestrated via `compose.prod.yml`:
* **Public Ingress:** Unprivileged NGINX Gateway on port 8080 (mapped to host port `7777`).
* **Presentation Layer:**
  * Next.js SSR Web App (`apps/web` on `http://web:7778`)
  * Admin React SPA (`apps/admin` on `http://admin:8080`)
  * Member Portal React SPA (`apps/portal` on `http://portal:8080`)
* **Domain Layer:**
  * Fastify REST API (`apps/api` on `http://api:7780`)
  * Background Worker (`apps/worker` on `http://worker:7782`)
* **Stateful Layer:**
  * PostgreSQL 16 Alpine (`postgres:16-alpine` on internal network `vibress-prod_backend`)
  * Redis 7 Alpine (`redis:7-alpine` on internal network `vibress-prod_backend` with AOF)
  * Object / Volume Storage (`vibress-prod_vibress_content`)
