## Domain responsibilities

### Auth
Identity verification, login sessions, token issuance, password flows, MFA hooks.

### Users / Roles / Permissions
Staff identity and RBAC/permission model.

### Posts / Pages
Editorial content lifecycle.

### Tags / Authors
Content classification and authorship.

### Revisions
Immutable or append-only history of editable content.

### Media / Files
Media metadata and storage references.

### Members
Public audience/customer identities.

### Products / Plans / Offers
Commercial catalog and entitlement definitions.

### Subscriptions / Billing
Subscription state and payment-provider lifecycle.

### Newsletters / Email
Editorial newsletter configuration and delivery orchestration.

### Comments
Discussion and moderation.

### Analytics
Event ingestion, aggregation, and reporting contracts.

### Integrations / Webhooks
Third-party platform connectivity.

### Automations
Rule-driven background actions.

### Themes
Theme metadata, validation, activation, and configuration.

### Settings
Typed installation/site settings.

### Audit
Security and administrative action history.
